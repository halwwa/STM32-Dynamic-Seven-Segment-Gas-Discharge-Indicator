# STM32 Dynamic Seven-Segment Gas-Discharge Indicator (Indicator12b)

Проект динамической индикации на микроконтроллере STM32F411CEU6. Устройство управляет четырьмя семисегментными индикаторами, отображая цифры от 0 до 9 одновременно на всех разрядах. 

## 🛠️ Аппаратная часть
* **Микроконтроллер:** STM32F411CEU6 (Black Pill)
* **Устройства:** 4 отдельные лампы с дешифратором.
* **Управление сегментами (A-D):** Пины `PB0`, `PB1`, `PB2`, `PB3` (подача двоичного кода 0-9).
* **Управление разрядами (Аноды):** Пины `PB4`, `PB5`, `PB6`, `PB7`.
* **Питание:** Используется boost-преобразователь (управляется через ШИМ `TIM3` на 100 кГц) для обеспечения необходимого напряжения на лампах.

## 📂 Структура проекта
* `Core/Src/main.c` — основной файл с логикой динамической индикации.
* `Core/Inc/main.h` — заголовочные файлы.
* `cmake/` — файлы конфигурации сборки CMake.
* `indicator12b.ioc` — файл конфигурации STM32CubeMX.

## 🧠 Логика работы
1. **Инициализация:** Настройка тактирования (PLL), портов GPIO и запуск ШИМ для boost-преобразователя.
2. **Динамическая индикация:** В бесконечном цикле `while(1)` происходит быстрое переключение разрядов (анодов) с частотой, незаметной для человеческого глаза.
3. **Защита от аппаратных проблем:** 
   * Перед подачей новой цифры все аноды гасятся.
   * Добавлена микро-пауза (пустой цикл) для закрытия транзисторов, чтобы избежать сквозного тока и тусклого свечения.
4. **Смена цифр:** С помощью системного таймера `HAL_GetTick()` раз в секунду происходит инкремент текущей цифры. На всех четырех лампах одновременно отображается одно и то же число (0000, 1111, 2222 и т.д.).

## 🚀 Как собрать и прошить
1. Откройте проект в **STM32CubeIDE** (или используйте VS Code с расширением STM32Cube).
2. Убедитесь, что все пути к компилятору `arm-none-eabi-gcc` настроены корректно (в файле `CMakeLists.txt` или `settings.json`).
3. Соберите проект (Build / F7).
4. Подключите плату через ST-Link и прошейте микроконтроллер (Run / Debug / F11).

## ⚠️ Важные замечания
* В функции `Set_Lamp` реализовано прямое управление регистром `GPIOB->ODR`. Убедитесь, что пины `PB4-PB7` настроены как `GPIO_Output` в CubeMX.
* Если какая-то из ламп не горит в динамическом режиме (но работает в статическом), проверьте номиналы базовых резисторов транзисторов или замените сам транзистор. Скорость закрытия ключей критична для мультиплексирования.
